## P1-004: Path Traversal in Wiki

#### Test: `pathTraversalAttackDetected`
```kotlin
@Test
fun pathTraversalAttackDetected() {
    val tempDir = Files.createTempDirectory("wiki-test")
    val weaponsDir = tempDir.resolve("Weapons").also { it.createDirectories() }
    
    try {
        val maliciousName = "Weapon/../../../etc/passwd"
        val filename = WikiPaths.weaponFilename(maliciousName)
        val targetPath = weaponsDir.resolve(filename)
        
        assertThrows(IllegalArgumentException::class.java) {
            val normalized = targetPath.normalize()
            require(normalized.startsWith(weaponsDir.normalize()))
        }
    } finally { tempDir.deleteRecursively() }
}
```
**Status:** FAILS → Passes after path validation

#### Test: `validFilenamesPassValidation`
